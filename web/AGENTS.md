- Chinese server schedules are enabled for Arknights, Girls’ Frontline 2 and Reverse:1999 by the owner’s latest request. Keep their cn schedules independent and verify Chinese official notices. Do not add Chinese schedules to the other games. Chinese remains available as a display language for all games.
- Every character, outfit, weapon and support card must match its illustration. Prefer the complete official gacha/pickup splash, with its effects and composition, over standalone character cutouts. An exact dedicated official pickup banner may be used when a clean full splash cannot be found; record that limitation. Never substitute another character or generic version art.
- Preserve the existing sidebar and information structure. Use large character artwork, restrained blurred backgrounds, diagonal framing and subtle transitions. Avoid lyrical marketing phrases.
- Owner edits are authoritative and stored as separate overrides. Automatic collection must preserve edited fields. Editing and image uploads require the verified owner identity on the server.
- GAGETHER is public by explicit owner request. Keep anonymous reading available. Protect /api/sync and /api/refresh with the server-side updater-token hash or verified editor identity; /api/editor and uploads remain owner-only.

- Arknights pickup coverage includes limited, standard and kernel pools for each actual region. Matching current rosters are valid; do not invent regional differences. Verify regional start/end clocks independently.
- Prefer Korean official banner artwork for Korean-first presentation when promotional images contain localized text. Preserve the exact character/outfit/equipment and full composition.
- Preserve entityDetails on routine updates. Base stats must declare level/ascension/sequence/rank assumptions; distinguish official skill facts from community numeric tables and keep actual verification timestamps.
- Preview artwork uses per-image face/subject focus and zoom; detail views show the complete original composition. Preserve owner previewFocus overrides and keep reviewed presets tied to exact source files.
- Calendar cells lead with schedule actions (pickup/event start or end). The dashboard calendar additionally shows each game name and groups by game; individual game calendars retain action-first labels. Ended schedules use a line-through only when a verified end time is in the past.
- Animation candidates require matching character/outfit, an appropriate player license, and actual playback verification before activation. Do not replace full illustrations with unverified loops or imply a preview animation was watched.

- Preserve the native dimensions/quality of verified original artwork; never downscale originals to a generic 1400/2048px asset pipeline. Seek genuine QHD/4K sources, but do not label smaller originals as 4K or synthesize detail. Preview zoom is limited by native pixels and device pixel ratio. Details retain the complete original.
- Text-bearing images need imageLocale and verified localizedArtwork. Use a matching text-free previewArtwork when available; unknown locale variants remain pending for unified services. For shared services use exact visitor imageLocale or verified neutral art. Latest owner clarification: explicitly selected independent regional services (including JP, CN and separate Global) show their exact current original art with an original-language label even on Korean UI; explanations remain translated. Do not mix another actual service or regional campaign into the default locale view. Official wallpapers used only as previews must be identified as wallpapers, never called original gacha splash art.
- First-visit language follows the edge-provided country (KR ko, JP ja, Chinese-language countries/regions zh, elsewhere en), with Accept-Language fallback when country is unavailable. Explicit visitor language choices override automatic detection. Do not store raw IP addresses or change game schedule canonical regions based on display language.
- Keep source links in compact bottom footnotes, preserving official/community/video distinctions and actual original links.

- Android companion loads the hosted /mobile page. Keep the mobile interface and API on the same Site so web releases reach the app without an APK update. Native notifications and widget changes still require an app build. Public browsing in the app requires no login; never embed Sites service credentials in APKs or browser code.
- /api/mobile/data is a read-only projection of effective editorial data. Keep canonical region mappings, honest null dates, localized artwork and the three explicitly supported Chinese services. Native deadlines must use these mappings rather than locale as the server.
- Mobile supports narrow Galaxy cover displays, ordinary phones, unfolded Fold screens and multi-window widths. No fixed orientation or aspect ratio. Preserve selected game/date on resize; honor system insets and font size.
- The Android beta uses local scheduled notifications and periodic public read-only sync, not FCM push. Do not claim instant server push before a Firebase project and sender credentials are connected and tested.

- Game headers use reviewed versionHero entries for the selected canonical service, with current version titles and official version key art. Exclude future/ended versions; retain owner edits. Version key art must never fill a character pickup image slot.
