# GAGETHER · 가게더

[운영 사이트](https://gagether.wiki/) · [Android 앱](https://github.com/tomochelly/gagether-android/releases/tag/v1.0.3)

18개 게임의 픽업·이벤트·방송·업데이트를 실제 서비스와 표시 언어로 구분하는 일정 서비스입니다.

## 구현 범위

- TypeScript·React/Vinext 웹, Cloudflare Workers·D1·R2 저장소, Android 알림·위젯.
- 공식 공지와 보완 자료 수집, 변경 본문 해시, 출처별 실패 보존, 단계별 재개, 전체/부분 실패 및 데이터 재조회 검증.
- 운영자 인라인 편집, 언어별 원본 이미지와 구도, 글자 크기·줄바꿈, 리비전 충돌 검사·이력·복원.
- 모바일 메뉴·달력·개별 픽업 상세와 실제 서비스별 다국어 URL·사이트맵.
- 개인 설정과 운영 데이터, 운영자 편집, 제보와 첨부, 익명 집계의 저장 경계를 분리합니다.

## 확인한 결과

2026-10-24 기준328개 웹 테스트, TypeScript 및 실제 SQLite/R2 편집·복원 검사 경로를 사용합니다. GitHub OIDC로 운영 갱신을 실제 완료했고 마지막 재조회는 automatic/effective 각각2100개, 검증 오류0건이었습니다. 일부 외부 출처의 제한과 추가 확인 상태는 partial로 남깁니다. Android1.0.3 알람·알림은 API30·36 에뮬레이터에서 확인했으며 실기기 절전 동작까지 보장하는 결과는 아닙니다.

## 공개 범위

- 이 저장소는 이미public이며 web 소스도 공개됩니다. 공개 코드만으로 운영 편집 권한이나 비밀 환경변수, D1/R2의 비공개 데이터가 제공되지는 않습니다.
- 비밀 환경변수·Android 개인 서명키·운영DB·사용자 제보/첨부·개인 동기화 데이터를 커밋하지 않습니다. 현재 코드의 알려진 키 패턴 검사에서 발견된 값은 없지만 전체 이력의 비밀 검사를 대신하지 않습니다.
- 운영 이메일과 운영 절차는 일부 코드/문서에 포함됩니다. 이 자료가 필요 없는 포트폴리오 전용 공개본에는 필요한 코드와 설명만 옮기는 편이 적절합니다. 기존 공개 이력은 현재 파일 삭제만으로 비공개가 되지 않습니다.
- 게임 로고·이미지·소개 자료와 제3자 코드의 권리는 원래 권리자에게 있습니다. 본인이 작성한 코드의 라이선스와 제3자 자산의 사용 조건을 구분합니다. 이 안내는 새로운 오픈소스 라이선스를 부여하지 않습니다.
