# 18게임 운영 및 복구

림버스 컴퍼니·듀엣 나이트 어비스·hololive Dreams를 기존15개와 동일한 라이브러리·편집·달력·앱 경로에 추가했습니다. 웹 v122 운영 배포와 추가 수집 실행, automatic/effective 재조회를 완료했습니다.

## 정상 갱신

- 기존 GitHub Actions의 OIDC 인증 `/api/fast-refresh` 경로를 그대로 사용합니다. 별도 Work 자동화를 켤 필요가 없습니다.
- 한국 원문을 먼저 수집하고 네이티브 Steam 11개 언어별 피드와 DNA 공식 웹4개 피드를 구분합니다. 앱·게시자·언어 ID를 검증하며 같은 공지의 언어별 저장ID도 분리합니다.
- 실제 본문은 기존 sourceBodies 경로로 게시합니다. 림버스 공개 편성표, hololive Dreams의 GameWith 보도자료 재게시를 추가 대조합니다. 커뮤니티 출처를 공식 원문으로 승격하지 않습니다.
- DNA 공식 한국 본문의 이벤트별 기간·보상을 추출합니다. 동명 반복 회차와1·2차 일정을 분리합니다. 캐릭터·무기 직접 획득과 외형 티켓은 가챠로 집계하지 않습니다.
- 수집 실패는 출처별로 남기고 기존 자료를 유지합니다. 중복 실행은20분 잠금으로 막고 종료 시 해제합니다. 같은 본문 해시는 verifiedAt을 다시 쓰지 않습니다.
- 전체 갱신은 한국 공지3개 단위 → 피드 → 지역 공지3개 단위 → 방송 채널6개 단위 → 방송6개 단위 → 본문·이벤트 → 최종 재조회를 단계별로 저장합니다. `continuation:true`가 반환되면 같은 인증 POST를 이어서 호출합니다. `busy:true`이면 retryAfter초 후 재호출합니다. 연결 중단은 저장 단계부터 재시도하며 마지막 readback 전에는 완료로 기록하지 않습니다.
- 버전 전체 본문은 개별 이벤트 section을 덮어쓰지 않으며 보상은 해당 이벤트 범위에서만 추출합니다. 본문 재조회는 기록한 각 언어를 구조적으로 비교하고 보존된 추가 언어나 운영자 편집을 저장 실패로 처리하지 않습니다.
- 등록된 정확한 원본 아트는 maintained-artwork 경로로 복구합니다. 새 캐릭터의 아직 조사하지 않은 아트·상세 수치는 자동 생성하지 않습니다. 현재 수동 보강한 스테이터스 전체의 자동 갱신까지 구현했다고 간주하지 않습니다.

## 운영 검증

- 초기21개 주요 항목 + 본문에서 추출한 현행/지난 이벤트·보완자료를 저장했습니다. 첫 실제 수집은79개 항목을 추가했고 추가 수집 출처13건은 모두 응답했습니다. 이 결과는 모든 게임의 모든 외부 출처 완전 성공을 뜻하지 않습니다.
- 변경 전1872개 항목은 모두 남아 있습니다. 기존 운영자 편집10개 항목의53개 편집 필드와 사이트 설정에 변경이 없음을 비교했습니다.
- 새 원본72개를 포함한429개 자산은 R2에서 SHA-256·바이트 수를 재확인했습니다. 공개 `/assets/` 주소는 고정이고 원본을 확대·재압축·삭제하지 않습니다. owner 업로드는 별도입니다.
- 날짜만 있는 hololive Dreams 기간은 화면에서 진행/종료를 구분하되 정확한 시각 알림과 Google 일정으로 만들지 않습니다.
- 구버전APK는15게임 호환 피드,1.0.3 이상은18게임 피드를 받습니다. 기존 즐겨찾기·알림 설정을 보호합니다.

## Work 없이 복구

1. GitHub의 `web/` 소스를 가져와 의존성을 설치합니다. `node ops/restore-assets.mjs`로 고정 원본을 복원합니다. manifest의 크기와 SHA-256이 다르면 중단합니다.
2. GitHub Actions 웹 검사와 `node scripts/validate-editor.mjs`를 실행합니다. 기존 인증·권한·CAS·업로드 분리 규칙을 유지합니다.
3. 일반 정보는 인증된 `/api/sync` 또는 운영자 인라인 편집기로 필요한 필드만 저장합니다. sourceBodies 수집은 `/api/collection`, 전체 정상 갱신은 `/api/fast-refresh`를 사용합니다.
4. 소스 변경은 Sites의 기존 프로젝트ID에 빌드·저장·배포합니다. GitHub main 커밋만으로 Sites가 자동 배포되는 연결은 없습니다.
5. 배포 실패 시 기존 저장 버전을 다시 배포합니다. 데이터는 기존 편집 이력·긴급 복구 경로를 사용합니다. R2 원본은 롤백 때 삭제하지 않습니다.

## 앱

Android1.0.3 / versionCode10을 기존 서명 인증서로 배포했습니다. API30·API36 에뮬레이터에서 새3게임 알람 예약과 실제 알림 수신 경로가 통과했습니다. 실제 사용자 휴대폰의 제조사 절전 환경은 별도 실기기 검수가 필요합니다.

## 남아 있는 한계

- DNA 일부 비한국어 공식 웹 피드는 오래되어 limited로 유지합니다. 현재 Steam 네이티브 원문을 병행합니다.
- hololive Dreams 일부 현재 편성·수치는 허용된 커뮤니티/보도자료 재게시 근거입니다. 시간대가 없는 기간에 시각을 합성하지 않습니다.
- 전체 기존 게임의 다른 언어 이미지 공백이 모두 해소된 것은 아닙니다. 기존 운영 감사의 누락 항목은 그대로 남깁니다.
- Discord 배포는 이번 범위에서 제외했습니다.
