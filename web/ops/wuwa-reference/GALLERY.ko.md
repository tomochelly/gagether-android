# 캐릭터 갤러리

연속 사선 목록 → 큰 캐릭터 상세 → 원본 전체 확대.12종씩 목록 이동, 등급/속성/무기/이름 검색을 조합한다. 상세는 Esc·닫기·앱 뒤로가기로 닫으며 스크롤과 포커스를 복원한다.

전체60종/원본ID64개를58개 전체 일러스트에 연결한다. 방랑자는 기본 의상의 남녀 원본을 각각 유지한다. 원형 초상과 IconRolePile 메뉴 이미지를 전체 일러스트로 사용하지 않는다. 근거·원본 해상도·종류·SHA256은 full-art-audit.json에 기록한다. 투명 원본은 알파 합성 상태로 검사한다.

원본은 Native Site Git의 public/reference-bootstrap과 별도 R2 wuwa-reference-art/에 보관한다. public 읽기 API는 알려진 SHA만 허용한다. 업로드는 기존 소유자/업데이터 인증 및 정확한 크기·SHA256을 요구하고 재조회한다. 다른 데이터·수동 편집·미디어는 변경하지 않는다. GitHub web 복구본은 코드/해시/보관 영수증을 포함하며 R2 원본은 scripts/restore-wuwa-full-art.mjs로 재다운로드해 검증할 수 있다.

기존6시간 참조 데이터 갱신은 공개 splashArt.ts에 실제 선언된 파일만 수집한다. 기존64개 ID는 고정 원본을 우선한다. 알 수 없는 신규 ID의 초상을 전체 일러스트로 승격하지 않는다. 빌드 전 check-wuwa-full-art.mjs가 원본 누락/해시 변경을 차단한다. 이전 Site 버전으로 코드 롤백해도 이 저장소는 별도 네임스페이스로 남는다.
