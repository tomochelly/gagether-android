# 상세 본문·스테이터스 표시 개선 · 2026-10-23

15개 게임의 모든 실제 서비스 및 ko/en/ja/zh에 공통 적용한다.

- 상품명 / 가격, 참가 조건, 진행 방법, 단계별 보상과 수량, 제한, 수령 기한을 짧은 문단·줄로 표시한다.
- 수집·검수·현지화 과정, 미확인 필드 안내, 운영자 화면 대조 과정은 공개 본문에서 제외한다. 원문·출처·확인 시각·일정 데이터·owner 편집 저장값은 보존한다.
- 예시 메가커피 항목은 4개 언어의 실제 데이터도 단계별 보상 형식으로 정리했다. 5스탬프 보상은 각각 1,000명 추첨이라는 조건을 유지했다.
- 기존 게임별 검수 자산에서 69개 속성/무기/병과 아이콘 정의를 재사용한다. 같은 게임·분류·정확한 값이 일치할 때만 다른 서비스의 같은 의미에 쓴다. 없는 게임 자산을 다른 게임 그림으로 채우지 않는다.
- 스테이터스는 아이콘 중심 분류와 작은 수치 카드로 표시한다. 실제 아이콘이 없는 숫자 항목은 공통 UI 기호를 사용한다. 레벨/장비 등 수치 기준은 접어 두며 실제 수치·스킬은 유지한다.
- 명조 자동 수집의 현재 무기 본문을 우선 처리한다. 보존되는 숨긴 무기 기록은 현재 목록과의 정상 공존이므로 중복 표시 장애로 판정하지 않는다. 실제 노출 캐릭터 중복 검사는 유지한다.

검증: 전체 247개 자동 테스트, TypeScript, 원본 보상 아이콘 운영 API의 PNG 응답, 329/360/390/420px 밝은/어두운 테마의 실제 컴포넌트 렌더링. 네 화면에서 가로 넘침 없이 아이콘이 로드되는 것을 확인했다. 원본 자산·해상도·owner override는 유지한다.
