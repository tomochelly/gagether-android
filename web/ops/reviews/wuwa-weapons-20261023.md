# 명조 전무 갱신 복구 · 2026-10-23

한국 홈페이지 ArticleMenu의 최신 일반 공지는 2026-09-30 업데이트였다. 현재 10월 21일 무기 튜닝 공지는 한국 공식 라운지의 인게임 공지(게시판 28)에 있었다. 기존 자동 수집의 한국 라운지 목록·본문 어댑터에 명조가 없었고, 수집된 일본/영어 본문도 무기 일정 데이터에 적용되지 않았다. 현재 전무 3종은 날짜만 있는 커뮤니티 예고 자료와 숨겨진 무기 기록으로 분리돼 있었다.

현재 한국어 원본 배너 3종을 각각 시각 검사했다. 원본은 모두 1920×1080이며 이름·5성·무기 종류·하위 4성 3종이 일치한다. 원본 크기와 파일을 유지한다.

자동 수집은 기존 10분 fast-refresh에 연결한다. 한국 라운지 28/1 목록 → 제목 저장 및 재조회 → SmartEditor 원문/원본 이미지 → 5성 전무·4성 확률 상승·각 기간 추출 → 기존 회차 ID 병합 또는 새 회차 생성 → 명시적으로 저장된 캐릭터/전무 관계 연결 → 저장 재조회 순서다. 동일 본문 재수집은 데이터 수정 시각을 다시 쓰지 않는다. 한국·일본·영어는 공통 global 일정이며 다른 서비스의 시각을 복사하지 않는다. 시간대 없는 신규 시각은 날짜만 유지한다.

이미지는 본문 원본을 즉시 제공하되 메인 카드의 특정 무기 그림을 파일 순서로 추정하지 않는다. 기존 검수 자산과 사용자 편집을 보존한다. 새 외국어 이름 대응이 없거나 공지의 시각이 충돌하면 기존 데이터를 유지하고 collection.weapons.issues 및 갱신 상태에 남긴다. 무기 pickupArchive는 새로 만들지 않는다.
