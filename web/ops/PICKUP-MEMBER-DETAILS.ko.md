# 캐릭터별 픽업 상세 · 보조 확률 상승 구성원

## 동작

- 명조의 루미·단근·치샤는 이미 `pickupMembers`, `role: rate-up`, `rarity: 4`로 저장되어 있었습니다. 보조 구성원은 메인 배너·픽업 카드·예정 카드에 작은 사진/이름/등급으로 표시합니다. 독립적인 풀 일러스트 카드나 신규·복각 주 픽업 개수에 포함하지 않습니다.
- 캐릭터 상세는 선택한 주 픽업 한 명의 이미지·스탯·스킬·재료·캐릭터 영상만 표시합니다. 4성 보조 구성원은 상세의 큰 이미지 영역이나 프로필 영역을 차지하지 않습니다.
- 블루 아카이브를 포함한 다중 주 픽업은 카드에서 고른 이름을 상세 선택 상태로 전달합니다. 전체 데이터 재조회·캐시·자동 폴링 후에도 선택을 유지합니다. 상세 상단의 작은 이름 버튼으로 같은 회차의 다른 주 픽업을 선택할 수 있습니다.
- 선택 모집/서포트 후보 풀은 기존 모델을 유지합니다. 무기·일정·저장 ID·운영자 이력도 유지합니다.

## 원인과 보호

기존 카드는 주 픽업별로 나뉘어 있었지만 클릭 시 전체 회차만 전달했습니다. 상세 재조회가 같은 ID의 전체 구성원과 전체 `entityDetails`를 복원하면서 다른 캐릭터 프로필까지 렌더링했습니다. 명조 상세 이미지도 `rate-up`까지 전체 그림 대상으로 포함해 불필요한 자리와 이미지 대기 영역이 생길 수 있었습니다.

회차 ID와 선택한 구성원을 분리하고, 표시할 때만 정확한 이름/의상을 기준으로 범위를 좁힙니다. 편집기는 완전한 원본을 사용합니다. 표시용 객체를 API 저장에 사용하지 않으며 운영 데이터를 삭제하거나 분할하지 않습니다. 주 픽업을 분리한 카드에서도 보조 구성원은 별도로 유지합니다.

우마무스메의 이미 저장된 신년 의상 2건은 공식 수식어와 설명식 의상 이름의 차이를 게임/실제 서비스/프로필 ID로 한정한 명시적 별칭으로 연결합니다. 다른 의상을 부분 문자열로 추정하지 않습니다.
