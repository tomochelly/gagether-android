# 이환 도감 상세 보강 · 2026-10-25

기존24개 도감 ID·서비스·일정은 유지했다. 200px 초상화13개와 이미지 공백을 기본 외형의 native원본25개로 교체했다. 제로는 여성1051을 기본으로 하고 남성1046을 선택할 수 있다. 그림뿐 아니라 성별별 스킬·패시브도 바뀐다. 같은 기초 성장 포인터를 사용하나 첫 기본공격 계수는 여성19.2%, 남성23%로 달라 동일하다고 합치지 않았다.

원본은 Global1.4.5의 DT_Character.ElementData.CharacterIllustration과 bIsManual·고유이름 키·EN/KO 이름으로 연결했다. Global/CN의 대응25파일 Gitblob과 크기가 같다는 근거를 global-art-equivalence.json에 보존했다. 모든 원본은2160×2560이며77,113,020bytes를 그대로 보존했다. 원본 자체가 무릎·허벅지에서 끝나는 그림도 있어card로 분류한다. 전신이나 가챠 풀일러로 가장하지 않는다. 전체원본뷰어에서 모든 원래 픽셀을 볼 수 있다.

## 수치와 상세

- Kaiden의 실제 Lv.1~80 HP/ATK/DEF 표1,920행. 선택한 레벨의 실제 행을 사용하며 보간하지 않는다.
- Global1.4.5 추출표의 기본 치명타·피해·에너지 필드. HP 성장표와 출처·기준을 구분한다.
- 스킬 표96개와549개 계수행, 스킬 Lv.1~13. 네 언어의 실제 클라이언트 명칭·항목명을 연결하고 안전하게 결합된 명시 수치만 표시했다.
- 패시브48개, 각성 효과189개, 콘솔 특화24개. 스토리·공략평가를 캐릭터 수치로 복사하지 않는다.
- 제로는 variantDetails로 남녀 각자의 원본 CharacterID·계수·패시브를 유지한다. 공통 HP 성장표는 같은 원시 성장 포인터라는 근거가 있다.
- 기본영어역할·등급 코드는 한국어/일본어/중국어 표시가 가능한 문구로 정리했고, 동일스킬·속성·아크유형의 실제 아이콘 경로를 확인했다.

## 확인된 한계

Adler80 수치가 Kaiden13122/382/912, 다른 DB8638/272/600으로 다르다. 원시값의 base/growth/stage 최종 합성식은 검증되지 않아 새 합계로 대체하지 않았다. HP/ATK/DEF는 Kaiden표로 명시하고, 기본치명타·에너지·스킬은 검증한 Global1.4.5 필드로 구분한다. 장비·각성 등의 별도 효과를 임의로 합산하거나 실제 최종 패널로 단정하지 않는다.

enrich_nte_details.py는 Global1.4.5 고정 소스다. 향후 클라이언트 버전을 자동 탐색한다고 주장하지 않는다. collect_nte_art.py는 README에 Global이라고 명시된 최신 불변 snapshot만 고른다. CN main이 최신이라는 이유로 진도·수치를 바꾸지 않는다. 네이티브 소스코드를 실행하지 않고 JSON과원문만 읽는다. 새 버전 지원은 동일한 ID·언어·수치 결합 검증 후 추가한다.

## 자동 수집·저장

기존6시간 도감 수집의b그룹에서 기본 수집 후 원본과상세를 보강한다. 각 단계의 실패는 이전입력을 보존하고 영수증에 남긴다. sourceId 집합과 ingest 크기를 검사한 파일만 전달한다. 서버는 기존3개 수치가 있는 R2스냅샷에도 새 항목을 ID별로 보충하고, 기본 초상화가 큰 원본을 다시 덮어쓰지 않게 한다. 기존상세·진행표·성별데이터는 sparse응답으로 지우지 않는다. 목록API는 큰 성장표·스킬·성별 상세를 빼고 클릭시읽는다.

GitHub 복구시web/에서 `node ops/restore-assets.mjs` 후 `node ops/restore-reference-artwork.mjs`를 실행한다. 원본은 크기와SHA256이 맞아야 하며 source파일은 리사이즈/압축하지 않는다. 내장 build guard가 모든고정원본을 검사한다.
