한국어 이름 슬롯에는 출처가 제공하지 않는 이름의 편집 번역도 포함한다. `nameSources.<locale>.kind=translation`으로 공식/커뮤니티 원문과 구분하며 화면에도 번역명으로 표시한다. 알려진 원본 ID와 원문 이름을 검증한 고정 번역표만 사용한다. 새 ID는 무조건 기존 이름으로 추정하지 않는다. 기존 지역 플래그와 픽업 데이터는 보존했다.

수치는 각 원문의 실제 기준이다. 원신 Lv.90/돌파6, 스타레일·젠레스·명일방주 Lv.1, 이환 Lv.80, DNA의 HP/실드/ATK Lv.1, 스텔라 Lv.1/돌파0, 엔드필드 클라이언트 v0.3.0의 명시된 Lv.90/돌파4 원시값 등으로 구별한다. 엔드필드 원시값은 속성에 의한 HP/ATK 보정도 제외해 최종 인게임 패널과 같다고 주장하지 않는다. 소전2 출처의 레벨 미기재 한계도 명시했다. 림버스는 원문 화면에 표시된 Lv.60 값과 Lv.1 값의 구별을 보존하며 레거시 필드명 hp_30만 보고 레벨을 추정하지 않는다.

붕괴3rd·트릭컬·홀로의 미제공 숫자와 출처에 없는 최신 엔드필드 7명, 리버스 4명, 림버스 1명은 추정하지 않았다. 상세 공급자 실패와 사실상 미제공은 개별 수집 보고서에 남는다.

## 원본

`content/character-rosters/artwork-manifest.json`과 `public/roster-bootstrap/`에 림버스 177개, DNA 29개, 붕괴3rd 한국어 아스카 소개 1개를 원래 바이트 그대로 고정했다. SHA256/크기/원본 URL/정확한 캐릭터 ID를 기록했다. DNA 29개는 하단이 사선으로 잘린 공식 소개 카드 원본이며 전신이나 가챠 풀일러로 가장하지 않는다. 전체 29개 연락 시트의 구도·텍스트 여부와 림버스 대표 파일을 시각 확인했지만 207개 개별 전수 시각 검수로 주장하지 않는다. 원본 링크와 언어/소개 캡션을 유지한다.

`node scripts/check-roster-artwork.mjs`는 빌드 전에 모든 고정 원본의 실제 해시와 크기를 확인한다. 새 파일을 임의로 리사이즈하거나 재인코딩하지 않는다. 수집기가 동일한 원본 URL을 다시 보내도 정확한 ID의 고정 파일로 연결한다.

## 자동 수집

기존 `../run.py`가 정상 수집한 canonical 입력만 `enrichment/run.py`로 보낸다. 별도 수집기는 이 디렉터리의 enrich_a.py~enrich_e.py다. `manual_names.json`, `ak-editorial-ko.json`, `extract_dna_literals.mjs`를 함께 배치해야 한다. Python 표준 라이브러리와 기존 Node/TypeScript를 사용한다. `pin_limbus_art.py`는 별도 수동 원본 고정 도구이며 Pillow가 필요하고 정기 수집 경로에서는 실행하지 않는다.

부가 수집의 캐시 디렉터리는 실행마다 새로 만들어 재생 캐시가 새 원문 확인으로 오인되지 않게 한다. 게임별 실패는 기존 canonical 입력을 보존하고, ID 집합 변경/ingest 용량 초과는 전달하지 않는다. 원문 실패·누락 수치·선언되지 않은 그림은 보고서에 남긴다. 부가 수집이 실패해도 서버의 `retainCharacterFacts`가 기존 이름·빈 배열로 사라질 수 있는 수치·상세·정확한 전체 그림을 보존한다. 운영에 이미 있던 R2 스냅샷에도 복구 스냅샷 보강이 읽기 시 적용된다. 실제 저장 해시와 보강 후 전달 해시를 분리해 이전 정상 포인터가 없는 객체를 가리키지 않게 했다.

초기 수집→별도 R2 불변 스냅샷→재조회→D1 포인터 CAS→재조회, OIDC 권한, 운영자 override, 다른 일정·즐겨찾기·개인 데이터는 기존 계약을 유지한다. 정상 canonical 전달과 부가 상세의 일부 실패는 영수증에서 구분한다.

## 화면과 검증

명조와 동일한 3열/모바일2열 연속 사선 갤러리, 행별 사선 전환, 내부 이음선 조명, 큰 상세 창을 적용했다. 원본 크기/DPR 한도, 작은 실제 초상 분류, 원본 보기, 실제 수치 기준, 검색/등급/이름 정렬, 지연 상세 읽기, 키보드 닫기/포커스/스크롤 복귀를 유지한다. 네이티브 앱 뒤로 가기에서 인식하는 공통 dialog 클래스도 유지한다.

386개 전체 회귀 테스트와 관련 데이터/저장/마운트 테스트, TypeScript 검사, Python 수집기 테스트를 실행했다. 로컬 Sites 미리보기는 supervisor가 실행 중이라고 보고했으나 cloud browser 연결은 ERR_CONNECTION_REFUSED였다. 실제 브라우저 시각 QA는 확인하지 못했으며 브라우저 통과로 표시하지 않는다.

파일을 이어받을 때 이 문서와 evidence/ 보고서, content의 스냅샷·고정 원본 manifest를 먼저 읽는다. 저장된 Site 버전과 Git 커밋을 확인한 뒤 변경을 계속한다.

## GitHub 소스에서 고정 파일 복원

GitHub 복구용 web/ 체크아웃은 기존 고용량 자산과 이번 고정 원본 바이트를 manifest로 복원한다. web/에서 `node ops/restore-assets.mjs` 후 `node ops/restore-roster-artwork.mjs`를 실행하고 빌드한다. 두 번째 도구는 이번 207개 고정 URL·SHA256·크기를 검사한다. 원본 바이트는 native Site Git와 저장된 배포 아카이브에 보존되어 있다.
