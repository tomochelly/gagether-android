# 블루 아카이브 상세 도감 자료 · 2026-10-25

`enrich_bluearchive_details.py`는 기존 블루 아카이브 도감 JSON에 실제 공개 자료의 전투 수치와 스킬을 결합한다. 사이트 쓰기 권한이나 소유자 자격 증명을 사용하지 않는다. 입력의 학생·의상 ID, 이름, 이미지, 서비스 공개 범위 및 다른 게임은 수정하지 않는다.

## 실행

```bash
python enrich_bluearchive_details.py \
  --input bluearchive.json \
  --output-dir output \
  --cache-dir work/bluearchive-details
```

결과는 `output/bluearchive.json`, ID별 사실 패치 `patches.json`, 출처·실제 해시·누락·단위 변환·크기 기록 `manifest.json`이다. 저장된 읽기 자료만으로 재검사할 때는 `--offline`을 추가한다. 기본 실행은 고정 공개 출처를 다시 읽는다. 접근 제한을 우회하거나 새 비공개 엔드포인트를 탐색하지 않는다. 읽기/검증/정확한 ID 결합/크기 검사가 실패하면 입력을 그대로 출력하고 실패 상태로 종료한다.

## 실제 범위

- 기존 학생·의상 278개 전체: HP·공격력·방어력·치유력의 압축 성장 정보와 상세 기초 수치.
- 274개: 네 언어 원본 스킬 설명 및 실제 단계별 매개변수. EX 1~5, 기본/강화/서브 1~10. 명시된 고유 무기 강화 스킬과 애용품 강화 스킬은 별도 항목이다.
- 최신 4개: 카스미(수영복) `20061`, 안나 `10151`, 에리나 `20062`, 츠무기 `10152`. 공개 Joe MCP의 실제 영어 스킬 16개를 수록한다. 원문은 1레벨~최대 레벨 범위만 제공하므로 중간 레벨 수치와 번역을 만들지 않는다. 원문 언어 대체 표시 및 범위 표기를 사용한다.
- 총 1,474개 스킬 항목: 단계별 네 언어 표 1,458개와 범위 원문 16개. 추가 효과 중 부모 단계와 정확히 결합되는 명시적 하위 스킬 22개를 포함한다.
- 지형 적성, 기본 피해 배율, 장비 슬롯, 배치·엄폐, 제공되는 고유 무기의 Lv.1 기초값도 구분해 수록한다. 무기 수치를 학생 기본 패널에 더하지 않는다.

## 출처와 버전

1. 한국 공식 사이트를 먼저 확인했다. Nexon 홈페이지는 해당 연구 환경의 접속 국가에 서비스하지 않는다는 응답이었다. 공식 학생 성장 가이드 `https://forum.nexon.com/bluearchive/board_view?board=1071&thread=2719465`의 공개 Nexon 게시물 API 원문은 별도 검증자가 확인했다. 이 가이드는 성장/애용품의 의미를 보강하며 수치 표의 공식 출처라는 의미가 아니다.
2. 네 언어 수치·스킬은 현재 기존 도감이 사용하는 공개 커뮤니티 포크 `nico0748/SchaleDB`의 완전한 Git 트리에서 실제 선언된 `data/{kr,en,jp,zh}/students.json`과 `localization.json`을 읽는다. 현재 고정된 참조는 `14bbca9ff89f3a9cf1c77d5d86dd359f45fd8c04`이다. 커밋 날짜는 2026-08-31, config의 빌드 시각은 2026-08-29이다. 원래 SchaleDB 저장소가 보관 상태인 점과 이 포크의 버전 제한을 숨기지 않는다.
3. 현재 학생 목록·공개 서비스·성장 앵커는 `https://ba.joexyz.online/api/students`에서 읽었다. 두 커뮤니티 자료에 공통으로 존재하는 274명의 HP/ATK/DEF/치유력 1/100 앵커 2,192개를 비교했고 차이가 없었다. 최신 4명의 앵커도 이 API에 실제 존재한다.
4. 최신 4명의 스킬은 Joe의 공개 MCP `https://ba.joexyz.online/mcp`가 선언한 읽기 전용 `get_student` 결과이다. `jozsefsallai/ba-tools` 커밋 `fd70147df536d9d6656e4d8d8c513cf17bbef829`의 `src/lib/mcp/tools/get-student.ts`, `src/app/mcp/route.ts` 및 `src/lib/mcp/server.json`에서 공개 도구를 확인했다. 요청의 정확한 slug와 응답의 Schale ID를 함께 검증한다. 일반 상세 페이지 경로를 추측하지 않고 이 실제 API를 출처로 둔다. 원시 응답과 SHA는 비공개 작업 기록에만 보관하고, 사이트에는 필요한 사실만 제공한다.
5. 현재 `schaledb.com/data/{kr,en,jp,zh}/students.min.json` 읽기는 HTTP 403으로 확인되었다. 우회나 반복 탐색을 하지 않았다.

## 기본 능력치 기준

성장 정보의 1~90은 이 참조판의 계산 범위이며, 최신 실제 서비스의 레벨 상한이라고 주장하지 않는다. 원본 `*1`과 `*100`은 성장식의 두 앵커이다. `100`을 현재 최대 레벨이라고 부르지 않는다. 기본 화면은 참조 Lv.90·태생 별 등급이다. 장비, 고유 무기, 인연, 잠재/능력 해방, 패시브 및 파티 보너스는 제외한다.

고정 출처 `js/common.js`의 `CharacterStats.interpolateStat` 및 생성자를 그대로 따른다.

```text
scale = Number(((level - 1) / 99).toFixed(4))
raw = Math.round((stat1 + (stat100 - stat1) * scale).toFixed(4))
total = Math.ceil((raw * starMultiplier).toFixed(4))
```

별 증가값은 10,000분율이며 별 개수만큼 누적한다.

| 수치 | 증가값 |
|---|---|
| HP | 0, 500, 700, 900, 1400 |
| ATK | 0, 1000, 1200, 1400, 1700 |
| 치유력 | 0, 750, 1000, 1200, 1500 |
| DEF | 별 보정 없음 |

예: 아루 Lv.90·태생 3★·위 보너스 제외 패널은 HP 19,776 / ATK 4,094 / DEF 109 / 치유력 4,630이다. 치명 수치 `201`은 확률 `201%`가 아니다. 원본 치명 대미지율 `20000`은 배율 단위 100으로 나누어 `200%`로 표시한다. 사거리와 코스트 회복력 등은 출처의 원시 수치 단위를 유지한다.

## 안전한 스킬 문장과 단위

`<?n>`를 자체 `{n}` 토큰으로 바꾸고 해당 언어의 실제 `Parameters[n-1]` 배열만 결합한다. 언어별 인덱스·문장 삽입·단위가 다른 77개 스킬이 있으므로 한 언어의 배열을 다른 원문에 억지로 대입하지 않는다. 같은 배열만 영어 기본 배열로 중복 제거하며, 다른 배열은 해당 언어 슬롯을 반드시 보존한다. 원본 버프/디버프/CC/특수효과 태그는 같은 출처의 `BuffName` 라벨로 치환한다. HTML을 실행하지 않는다. 원문 빈 설명은 빈 언어 슬롯으로 남기고 실제 영어 원문으로 대체한다.

46개 원시 rate-base 매개변수 배열은 정확한 `Effects.Value` 배열과의 완전한 일치 및 `CharacterStats.isRateStat` 규칙으로 확인한 뒤 `%p`로 변환한다. 예: 아루 고유 무기 강화 스킬의 `CriticalDamageRate_Base` 2000→20%p, 3800→38%p. HP나 공격력의 정수 증가, 치명/회피 점수, 이미 `%`가 있는 문자열은 임의로 나누지 않는다. 각 원시 배열·표시 배열·학생/스킬/매개변수 ID·효과 필드는 manifest에 남는다.

애용품 기본 스킬+는 T2 조건을 표시하고 자료에 실제 열린 서비스만 표시한다. 고유 무기 강화 스킬+는 ★2 조건을 표시한다. 이 스킬들의 보너스를 기본 능력치에 합산하지 않는다. 기존 도감/현재 Joe 공개 서비스 범위를 오래된 포크의 학생 공개 플래그로 낮추지 않는다.

## 실제 한계와 검증

- 부모 EX는 5단계인데 하위 효과는 10개 행으로만 제공되는 네 사례는 단계 대응을 추측하지 않고 생략했다. ID와 원인은 manifest의 `omissions`에 기록되어 있다. 나머지 부모 스킬은 유지한다.
- 원본 포크에 없는 최신 4명의 고유 무기/새 애용품 상세나 단계별 계수를 꾸며 넣지 않는다.
- 에리나의 새 특수효과는 원문에 `Special_CH0321_Ex`라는 내부키만 있었다. 고유 이름을 지어내지 않고 문맥상 'an additional effect'로만 기술했다. 효과의 ATK 범위·대상·종료 조건은 원문 그대로 유지한다.
- 같은 입력과 캐시로 재실행했을 때 사실 패치가 완전히 같고, 시간 필드를 제외한 출력이 같음을 확인했다. 기존 ID·이름·이미지·서비스 필드도 전부 유지된다.
- 별도 검증자가 만든 원본 계산기 수치 표본과 대조한 결과는 `verification.json`에 기록되어 있다. 실제 애플리케이션 스키마 검증도 278개 전부 통과했다.
- 최종 JSON은 기본 Python `json.dumps(..., ensure_ascii=False)` 직렬화 기준 약 4.30MB, 압축 직렬화 약 4.02MB이다. API 전달 제한 4.4MB를 둘 다 검사한다. 한도를 넘으면 부분 자료를 성공으로 내보내지 않는다.

## 사이트 통합 · 2026-10-25

기본 성장표의 접힌 기준에는 원본 빌드일 2026-08-29를 표시한다. 표시 버전은 빌드일과 Joe 인벤토리 해시로 축약하며, 전체 커밋은 출처 URL과 수집 영수증에 보존한다. 기본 성장식은 레벨 1~90의 참조 계산이며 실제 최신 서버 상한을 주장하지 않는다.

상세 항목은 캐릭터를 열 때 읽는다. 최초 목록에서 스탯·성장식·스킬 매개변수·상세 문단을 제외한다. EX와 다른 스킬의 레벨 선택은 독립적이며, 애용품 강화는 제공된 실제 서비스 범위로 제한한다. 영어 범위만 있는 최신 4명은 원문 언어를 표시하고 중간 계수를 만들지 않는다. 기존 의상 ID·지역·이미지·다른 게임 자료를 유지한다.
