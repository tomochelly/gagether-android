# 젠레스 도감 원본·상세 보강

현재 도감의 61개 ID를 그대로 유지한다. 공식 한국어 홈페이지의 선언된 캐릭터 API를 먼저 확인하고, 해당 인물의 공식 소개 전체 일러스트를 가져온다. 신규·미출시 인물을 원본 목록에 있다는 이유만으로 추가하지 않는다. 기존 카드 이미지도 보조 원본으로 보존한다. 이 원본들은 공식 소개용 전신 일러스트이며 가챠 스플래시라는 표기는 하지 않는다.

`enrich.py --input <zzz.json> --output-dir <directory> [--cache-dir <directory>]`로 실행한다. Python 표준 라이브러리와 Pillow, 기존 TypeScript 의존성을 사용한다. 사이트 쓰기나 인증 정보는 없다. 정상 수집은 고정된 공식/Enka/ZZZ.gg 출처와 그 페이지가 실제 선언한 파일만 읽는다. ZZZ.gg JavaScript 파일은 `parse-catalog.mjs`의 TypeScript AST로 정적 JSON/리터럴만 해석하며 import, eval 또는 다운로드한 코드 실행은 하지 않는다.

출력은 `zzz.json`, `artwork-inventory.json`, `manifest.json`, 해시 이름의 `assets/` 원본이다. 운영 합성은 기존 정확한 이미지 URL에 묶인 owner 구도를 계속 보존해야 한다. 원본을 재인코딩하거나 해상도를 늘리지 않는다. 개별 원본 실패는 기존 이미지와 상세를 지키고 실패를 기록한다. 전체 출처 실패는 입력을 그대로 출력하며 실패 상태로 끝난다. `partial`은 완료 성공과 구별한다.

최종 확인값은 `detail-manifest.json`에 있다. 61개 전신 원본 50,006,381바이트, 909개 기본 스킬 설명, 핵심 스킬 122개, 시네마 366개와 별도 수치 변형 15개로 총 1,412개 표를 만들었다. 서로 다른 출처 수치 행 2,595개가 각각 한 번씩 포함되는지 검사한다. 설명 제목과 다른 자세·공격 수치 제목도 별도 표로 보존하며, 누락이나 중복이 있으면 해당 캐릭터 보강을 거부한다.

피로이스의 시네마6은 현재 원문도 「시네마 효과 미공개」이고 프로필은 null이다. 그 상태를 보존하며 효과·키·생일 등을 만들지 않는다. 366개 표가 모두 공개된 효과 366개라는 뜻은 아니다.

스킬 수치는 Lv.1–12를 제공하고 참조 스킬도 같은 선택 레벨로 계산한다. 시네마 레벨 증가는 포함하지 않는다. 핵심 스킬은 기본/A–F의 일곱 원문을 제공한다. 숫자만 바뀌는 부분은 매개변수로 보관하고, 원문 문구가 달라지는 경우에도 길이가 제한된 텍스트 매개변수로 원문 전체를 손실 없이 보존한다. 공식 조작 아이콘은 해당 버튼 이름으로 치환하며 줄바꿈과 원문의 조건·수치를 남긴다. 높이·생일·성별·소속과 육성 재료는 가져오고, 긴 세계관 소개문은 이번 스테이터스 보강 범위에 넣지 않았다.

기본 패널은 Lv.60, 승급5, 핵심 강화0이며 음동기·디스크·시네마 효과를 제외한다. Enka의 기본+성장+승급 공식을 사용하고 정수 능력치는 버린다. 각 승급 단계의 정확한 시작/끝 총12개 체크포인트를 제공한다. 알려지지 않은 성장 곡선을 보간하지 않는다. 핵심 A–F 효과는 기본 패널에 섞지 않는다.

실제 한국어 ZZZ.gg 엔비 화면은 Lv.60 HP7500/공격658/방어612/충격136을 표시한다. 같은 출처의 핵심F 표는 공격75/충격18을 더한다. 이번 핵심0 계산값은7500/583/612/118이며 그 보너스를 분리하면 일치한다. 이는 서로 다른 제공 출처의 일관성 확인이며 독립적인 인게임 측정이라고 주장하지 않는다.

`--replay-source-root <directory>`는 운영 수집과 구별되는 재현 검증용이다. 정확한 URL·크기·SHA256·원래 HTTP 확인 시각이 담긴 영수증과 바이트가 일치해야만 사용한다. 이 경우 `via: hash-verified-source-replay`를 기록하고 원래 출처 확인 시각을 유지한다. 바깥 생성 시각은 새 출처 확인의 증거가 아니다.

검증: `python3 -m unittest discover -s ops/character-rosters/enrichment/zzz -p 'test_*.py'` 8개 통과. 실제 도감 스키마 통과, 전체 언어/레벨 설명 43,908개에서 미해결 원문 마크업·매개변수가 없음을 확인했다. 모든 원본을 다시 해시 검사했고, 일반 알파 합성 화면에서 전신·문자 없는 구도·정확한 인물을 확인했다. 투명 픽셀의 보이지 않는 RGB 잔여값은 원본 그대로 보존한다.

이 보강의 전체 도감 스냅샷과 기존 복구 조각은 기존 canonical-only 정책을 따른다. 공개 코드 미러가 전체 운영 데이터 백업이라는 뜻은 아니다.
