# 모바일 메뉴·문장 편집·검색 노출

## 모바일 메뉴

- 화면 왼쪽24px에서 오른쪽으로64px 이상,900ms 안에 수평으로 밀면 기존 카테고리/게임 메뉴가 열립니다. 메뉴 안에서 왼쪽으로 밀거나 닫기·배경·Escape로 닫습니다.
- 세로 스크롤, 다중 터치, 입력 필드, 이미지 편집과 모달에서는 열지 않습니다. 배경 inert, 초점 순환·복귀와 스크롤 복귀를 적용합니다. 넓은 화면으로 전환되면 메뉴 잠금도 해제합니다.
- 실제 OS가 가져가는 시스템 가장자리 제스처는 웹 페이지가 보장할 수 없습니다. 기존 메뉴 버튼을 유지합니다. 실기기 터치 검수와 DOM에서 실제 마운트한 터치 이벤트 검사는 구분합니다.

## 글 편집

- `Entry.textStyle[ko|en|ja|zh]`에서 titleSize(12–56px),bodySize(10–32px),lineHeight(1.2–2.4)를 저장합니다. 각 언어의 초기화는 그 언어만 변경합니다. 개별 글 블록에도 같은 서식을 저장할 수 있습니다.
- 제목은 여러 줄 입력, 요약/상세는 줄바꿈·빈 줄·들여쓰기를 지원합니다. 운영자 작성 필드는 자동 요약 문장 분리 대신 입력 그대로 표시합니다. HTML은 실행하지 않습니다.
- 기존 인증·리비전 충돌·임시 입력·이력·복원 경로를 사용합니다. 글자 크기는 일반 CSS 문자열이 아닌 검증된 숫자만 허용합니다. 일반 수집이 서식이나 운영자 텍스트를 변경하지 않습니다.

## 검색

- 사이트 이름 ‘가게더’, 한국어 주요 제목 ‘가게더 픽업 캘린더’,18게임 설명 및 신규3게임 소개를 일치시킵니다. 검색어를 숨겨 반복하거나 keywords로 순위를 약속하지 않습니다.
- 사이트맵은 모든 게임의 실제 서비스와4개 언어를 수록합니다. hreflang은 언어가 바뀌어도 같은 실제 서비스를 가리키며, 언어별 기본 서비스 경로는 쿼리 없이 정규화합니다.
- 배포 전 운영의 robots.txt·sitemap.xml은HTTP200이었습니다. 검색 결과에 한국어 페이지가 노출되는 것은 확인했지만, Google Search Console의 노출·클릭·제외 사유나 특정 키워드 순위는 조회하지 않았습니다. 재색인 요청/반영을 완료했다고 주장하지 않습니다.

## 공개 소스와 포트폴리오

- 현재 GitHub 저장소는 이미public이며 web도 공개돼 있습니다. 현재 추적한 텍스트728개에서 알려진 키 패턴은 발견되지 않았고 .env·개인 서명키·운영DB는 추적되지 않았습니다. 전체 커밋 이력 또는 공식 secret scanning 감사를 대신하지 않습니다.
- 운영 이메일과 운영 지침은 코드/문서에 포함됩니다. 포트폴리오 공개본을 별도로 만든다면 이런 운영 자료는 필요한 것만 옮기세요. 이미 공개된 이력은 현재 파일만 지워서 비공개로 만들 수 없습니다.
- 공개 코드는 운영 데이터나 편집 권한을 제공하지 않습니다. 서버 인증과 권한 검증을 유지합니다. 게임 이미지/로고/제3자 코드는 본인 저작물로 재라이선스하지 말고 원래 출처·권리·라이선스를 보존합니다. 코드 공개와 이용 허락 라이선스 선택은 별개입니다.
