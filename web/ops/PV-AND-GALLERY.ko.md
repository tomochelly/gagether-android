일반 업로드 PV가 빠진 원인은 빠른 갱신이 `/streams`의 방송만 수집하고, `official_channels.posts`의 일반 업로드를 갱신하지 않았기 때문이다. `/videos`의 `ytInitialData`가 assignment가 아닌 JSON script인 실제 영어 채널 형식도 추가 지원한다.

`uploads` 체크포인트는 한국어 공식 채널을 우선하고 한 요청에3채널을 확인한다. RSS 실패 시 같은 등록 채널의 일반 영상 목록을 확인한다. 정확한 채널 ID·동영상 ID를 검증하고, 실제 게시 시각은 RSS가 제공한 경우에만 저장한다. 상대 시각은 최근 발견 여부에만 쓰며 시각을 역산하지 않는다. 새 영상은 별도 안정 ID로 저장하고 기존 원본·수동 편집을 유지한다. 실패 시 이전 게시물도 유지한다. 기존 GitHub 요청 루프의 요청 상한은 새 단계를 포함하도록120으로 늘렸다. 저장 버전/배포와 외부 자동 작업 저장소의 workflow 소스는 별개이므로, 기존 원격 workflow의80회 한도에서도 중간 체크포인트는 다음 실행에 이어진다.

대시보드·게임별 신규 PV 배너는 게시 시각 또는 실제 첫 발견 시각을 기준으로7일간 표시한다. 새로운 검사는 그 시각을 갱신하지 않는다. 재생 버튼을 눌러야 iframe을 마운트하고 닫기/언어 전환 시 재생을 제거한다. 픽업 일정과 방송 상태는 PV에서 추정하지 않는다. 기존 화면 순서는 보존하고 신규 영역만 픽업 앞에 추가한다. Simple 화면은 펼친 뒤 그림/플레이어를 마운트한다.
