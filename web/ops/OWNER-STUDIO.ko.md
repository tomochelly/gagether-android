# 관리자 현장 편집기

이 기능은 `/owner`에서 인증한 허용된 운영자에게만 보입니다. 일반 방문자·자동 수집 토큰은 편집 API와 업로드 API를 사용할 수 없습니다.

## 사진 배치

1. 해당 배너·카드의 `사진` 또는 `편집`을 누릅니다. 여러 픽업이면 구성원별 사진을 각각 선택합니다.
2. 파일을 올리거나 끌어 넣거나 클립보드 사진을 붙여넣습니다. 업로드 중에는 저장할 수 없습니다. 실패하면 재시도하거나 교체를 취소합니다.
3. `구도 · 위치 조정`에서 공통·배너·카드·모바일 배너를 고릅니다. 열었던 항목에서 측정 가능한 경우 그 표시 영역 크기를 초기 틀로 사용합니다. 다른 틀은 예시 크기이며 너비·높이를 바꿔 시험할 수 있습니다.
4. 사진을 드래그하거나 화살표 키로 이동합니다. Shift+방향키는 크게 이동합니다. 확대·축소 버튼과 슬라이더, 전체 맞춤·틀 채우기·가운데 버튼을 사용할 수 있습니다.
5. 테두리와 3등분 안내선 안쪽이 표시 영역입니다. 배너는 모바일/배너/공통 순으로, 카드는 카드/공통 순으로 설정을 적용합니다. 모바일 설정이 없으면 배너 구도를 이어 씁니다.
6. 저장하면 해당 항목의 관리자 오버라이드만 갱신합니다. 원본 파일은 재크롭·압축하지 않으며 상세 전체 원본 보기는 유지합니다. 화면 크기에 따라 보이는 범위는 달라질 수 있습니다. 확대는 원본 픽셀 상한을 유지하므로 작은 원본에는 여백과 기존 블러 처리가 남을 수 있습니다.

`자동 구도 복원`은 선택한 표시 종류의 위치 설정만 해제합니다. 다른 표시 종류의 설정이나 업로드 원본은 지우지 않습니다. 사진 자체를 교체하면 이전 사진의 위치·지역화·크롭 참조가 새 사진으로 잘못 넘어가지 않도록 초기화합니다.

## 재화와 보상

- 현장 편집의 `글`·`상세`·전체 편집에 `보상 · 가챠 재화`가 있습니다.
- 게임 재화 버튼을 누르면 해당 게임의 검수된 카탈로그 이름·분류·아이콘을 불러옵니다. 그림이 검수되지 않은 재화는 글로 표시합니다. 다른 게임 그림으로 대신 채우지 않습니다.
- 수량, 무료/조건부/구매, 참여 조건·일일 제한·수령/교환 마감, 근거 URL을 입력합니다. 재화를 선택했다는 사실이 해당 행사 보상 지급을 증명하지는 않습니다.
- 수량은 카드·간단 화면·상세에 표시합니다. 가챠 재화/티켓으로 지정한 경우 요약 칩에도 나타납니다. 일반 자원은 상세에 표시합니다.
- KO/EN/JA/ZH 탭으로 이름·설명을 따로 입력합니다. 카탈로그 출처와 공식 현지화/번역 표기는 보존하며, 직접 변경한 이름은 자동으로 공식 이름이 되지 않습니다.
- 아이콘을 직접 교체할 수도 있습니다. 빈 이름이나 HTTPS가 아닌 근거 주소는 저장 오류에 위치를 표시합니다. 저장 실패 시 입력은 유지됩니다.

## 화면 순서

편집 모드의 `화면 구성 · 순서`를 누릅니다. 홈·게임 화면·달력 화면별로 주기 콘텐츠, 업데이트 배너, 방송, 달력, 내 게임 공지, 픽업 배너, 이벤트, 예정 픽업, 갱신 상태·관리, 콘텐츠 목록, 공식 SNS의 순서를 변경할 수 있습니다. 실제 그 화면에 있는 영역에만 이동 손잡이가 나타납니다.

손잡이를 끌거나 위·아래 버튼을 누른 후 `구성 저장`합니다. 저장 전에는 현재 편집 브라우저에만 보이고, 저장 후 모든 방문자의 해당 화면 종류에 반영됩니다. 방문자의 즐겨찾기·개인 게임 순서·메모와 별개입니다. 설정하지 않은 화면은 기존 순서를 유지합니다.

다른 창에서 사이트 설정을 변경했으면 저장을 409로 거부하며 내 순서를 보관합니다. `최신 설정과 비교`로 최신 브랜드·공지 등 설정을 읽고, 보관한 순서를 확인하여 다시 저장합니다. 페이지를 벗어나면 세션에 임시 순서를 보관하고 다음에 `보관된 순서 복구`로 가져올 수 있습니다. `기본 순서`와 `구성 변경 이력`의 이전 순서는 먼저 편집 초안으로 불러오며, 저장해야 반영됩니다. 이력 복원은 해당 화면의 순서만 바꾸므로 다른 사이트 설정을 되돌리지 않습니다.

## 저장과 복구

- 항목 저장은 기존 `/api/editor?view=entry`, 화면 구성은 작은 설정 전용 `/api/editor?view=settings`를 사용합니다. 서버는 인증·동일 출처·스키마·revision을 확인합니다.
- 화면 구성 저장 후에는 GET으로 다시 읽어 요청한 순서를 비교합니다. 불확실한 응답을 성공으로 표시하지 않습니다.
- 변경 이력은 기존 원자적 SQLite 감사 트리거에 기록합니다. 항목의 이전 버전 복원과 사이트 설정 이력은 기존 소유자 전용 경로를 사용합니다.
- 자동 수집은 관리자 `imageFraming`, 보상, 사진과 사이트 설정을 덮어쓰지 않습니다.

## 검증 범위

실제 컴포넌트 마운트/하이드레이션 검사와 격리된 SQLite/R2의 실제 API 경로로 드래그·키보드·축소·확대, 카드/배너별 저장값, 원본 보존, 15개 게임 재화 선택, 4개 언어 표시, 순서 변경, 저장 실패·충돌·이력 복원을 검증합니다. 운영자 실데이터를 시험용 값으로 바꾸지 않습니다. 현재 관리형 미리보기 환경의 기존 서버 충돌 때문에 실제 브라우저 시각 검수와 운영자 로그인 세션에서의 실서비스 저장 시연은 미검증입니다. 컴포넌트 검사를 실제 브라우저 검사로 부르지 않습니다.
