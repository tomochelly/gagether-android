# 픽업·버전 이미지 복구 및 LIVE 표시 검증 —2026-10-23

젠레스 등 동시 픽업은 회차별 원본 데이터를 유지하며 현재 목록에서 캐릭터별
카드로 표시한다. 각 카드에는 자신의 검수된 그림만 연결한다. 하위 확률 상승은
별도 주 픽업 카드로 만들지 않으며 선택 모집은 한 풀로 유지한다. 원본ID,
달력, 저장 항목, 커뮤니티 대상 및 관리자 수정 이력은 복제하지 않는다.

트릭컬3주년 헤더는10월22일 종료됐고 외부 원본은404였다. 현재 공식 홈페이지와
10월22일 업데이트 본문을 대조해 코페의 정확한1200×630공식 소개 포스터를
확보했다. 과거3주년 그림을 코페로 교체하지 않는다. 과거 원본의 보관본은 찾지
못했으며 미복구 상태다. 현재 소개 그림은 가챠 원화라고 표기하지 않는다.

붕괴3rd는 JP→KR공통 일정에서 일본어 그림 슬롯이 빠졌고9.0헤더가 만료된
상태였다. 한국167008/일본166999/글로벌166943공식 본문을 각각 읽어9.1을
검수했다. 버전 안내는 한국1200×675, 일본1190×247, 영어1080×540원본이다.
시간의 율자 전체 무문자 공식 소개 그림3336×1500과 세나디아 일본 공식
800×400소개 그림도 검수했다. 세나디아는2026-08-20최초 소개임을 캡션에
밝힌다. 현재 복각 근거와 과거 소개 기간을 혼동하지 않는다.

재발 방지:

- HI3한국·글로벌 공식 홈페이지 API를 수집기에 추가하고 JP와 분리했다.
- 트릭컬 JS화면 대신 공식 Naver라운지의 정상 공개 API 본문을 읽고 ID를 검사한다.
- 모든15게임/26실제 서비스/4언어의 현재 헤더 및 주요 픽업 이미지 공백을
  `/api/collection`과 운영자 대시보드에 표시한다. 수록은 완전 수집·시각 검수가 아니다.
- 수집 시 생략한 검수 그림·언어·구성원 이미지를 보존한다. 새 파일에는 이전
  이미지의 언어·구도를 자동으로 붙이지 않는다. 다른 의상의 그림도 승계하지 않는다.
- 콘텐츠가 없는 배너와 잘못 연결된 게임 로고는 큰 픽업 그림으로 대체 표시하지 않는다.
- 신규 고정 원본은 R2복사 전에도 배포본의 크기·SHA-256일치 원본으로 제공한다.
  실패 시 가짜 그림을 반환하지 않는다. 이전 R2원본과 owner미디어는 유지한다.

LIVE는 공식 메타데이터가 실제 live인 경우 라이브러리·사이드바에 표시한다.
예약 시각 경과만으로 LIVE로 바꾸지 않는다. 열린 페이지는 저장 데이터를1분마다
조회하고, 기존 공식 수집은10분 목표의 best-effort이므로 정각 보장은 없다.
종료/취소/오래된 LIVE는 숨긴다. YouTube로그인 제한은 방송 종료로 추정하지 않는다.

검증: TypeScript,210개자동화테스트, 관리자API/SQLite/R2저장·충돌·복원 검증 통과.
현재/가장 가까운 예정에 선택되는 원본118개HTTP이미지 응답 확인. 한국·영어·
일본어·중국어에서 개별 카드와 예약→LIVE→종료 전환을 실제 React DOM으로 시험했다.
이는 브라우저 스크린샷 검증과 다르다. 관리 미리보기의 이전 서버 충돌이
해소됐다는 증거가 없어 브라우저 시각 검수는 미완료로 유지한다.

운영 반영 여부와 정확한 Site저장 버전·커밋은 `ops/release.json`을 확인한다.

### 운영 후속 확인

v93배포 후 자동 갱신 요청에서 Worker1102가 관찰됐다. 전체10MB대 카탈로그의
상세·그림을 수집 여러 단계 및 항목별 저장에서 반복 읽는 경로를 보강한다.
수집은 별도의 최소 메타데이터 SQL투영을 사용하고, 저장은 변경ID만 전체 원문을
읽어 기존 상세·그림·언어·owner값을 보존한다. 최소 투영은 공개 카탈로그로
전송하지 않는다. DB스키마 변경이나 원본 데이터 축소는 없다. 실제 운영 재실행의
성공/부분실패는 실행 결과와 `ops/release.json`에서 별도로 확인해야 한다.
