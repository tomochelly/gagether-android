# GAGETHER Android
[한국어](README.md) · [English](README.en.md) · 日本語

> お気に入りのゲームも、見逃したくない予定も、ひとつのカレンダーに。

**GAGETHER** は、ゲームごとに分散するピックアップ・イベント・終了間近の予定をまとめるガチャゲームカレンダーです。Androidアプリでは、共通のモバイルWeb画面に通知とホーム画面ウィジェットを組み合わせています。

[Webで使う](https://gagether.wiki) · [リリース／ダウンロード](https://github.com/tomochelly/gagether-android/releases) · [変更履歴](CHANGELOG.md)

## 主な機能

| 機能 | できること |
| --- | --- |
| お気に入り | ゲームと実際のサービス地域を選んで予定を確認 |
| ウィジェット | 次の予定・スクロールできる予定一覧・ゲーム別表示を選択 |
| 通知設定 | 開始／終了と複数の事前通知タイミングを設定 |
| シンプル表示 | 必要なときだけイラストを開いてスクロールを軽減 |
| 個人カレンダー | メモ・ガチャ記録・個人の予定を利用中の端末に保存 |
| Webとの連携 | Webの情報・画面更新をAPKの再インストールなしで反映 |

**はじめに：** Webはログインせずに閲覧できます。インストール用APKとソース圧縮ファイルは別のものです。現在の配布状況は下記とReleasesをご確認ください。通知は端末内で予約する方式です。

## リリース状況

[GAGETHER](https://gagether.wiki) のAndroidコンパニオンアプリです。ガチャゲームのピックアップ、イベント、販売パックの日程をまとめます。リリース用署名済み **[GAGETHER 1.0.3 APK](https://github.com/tomochelly/gagether-android/releases/tag/v1.0.3)**（versionCode 10）を公開しています。Assetsの `GAGETHER-1.0.3.apk` をダウンロードしてください。ソース圧縮ファイルはインストーラーではありません。release単体テスト、APK/AABビルド、APK署名検証が成功しました。Google Play／Galaxy Storeではまだ公開していません。

アプリIDは `app.patchwork.radar` です。従来の `.beta` アプリとは別にインストールされ、設定や個人記録は自動移行されません。

## 課題と設計
ゲームやサービスごとに分散する情報を、共通のモバイルWeb画面とAndroidの通知・ホーム画面ウィジェットで確認できるようにしました。Web画面と情報の更新はAPKの再インストールなしで反映されます。ネイティブ機能の変更にはアプリ更新が必要です。

## 実装済み
- ログイン不要の公開閲覧、お気に入りゲームと実際のサービス地域の選択。
- 次の予定・予定一覧・ゲーム別のサイズ変更可能なウィジェット。
- コンテンツ別の開始／終了通知、複数の事前通知時刻、夜間通知の抑制。
- スマートフォン、Foldのカバー／内側画面、マルチウィンドウの幅に対応するWebレイアウト。
- 任意のシンプル表示、端末内に保存するカレンダーメモ・ガチャ記録。
- 公開APIの読み取り専用同期、データ検証、古い情報の通知抑制と再予約。
- 任意のキャラクター風通知文。公式台詞ではなく創作文と明記し、未検証の人物・言語では通常文を使用。

## 技術と判断
Android側はJava、WebView/WebMessage、JobScheduler、AlarmManager、RemoteViewsを使用します。Web側は別途ホストされたReact/TypeScriptサービスです。このリポジトリにはAndroidアプリと `web/` のReact/TypeScriptサービスソースを収録しています。運用データベース・個人署名鍵・非公開ユーザーデータは含めません。[Webポートフォリオと公開範囲](web/PORTFOLIO.md)・[検証記録](web/ops/catalog-expansion/verification-20261024.json)を参照してください。

表示言語とゲームのサービス地域は分離しています。未確認・予測・日付のみの予定から正確な通知時刻を生成しません。更新用認証情報や管理者セッションをアプリに埋め込まず、個人メモも公開データへ送信しません。

## ポートフォリオとして
企画者が課題設定、情報の優先順位、利用者の意見に基づく改善を主導した、AI支援による個人開発プロジェクトです。AIは実装・調査・テストを補助しました。実装と検証の範囲を分けて記録し、今後必要な実機検証や性能測定も明示しています。

評価対象として、Webとネイティブの責務分離、入力検証、多言語化、可変画面への対応、不確実な日程の扱いをコードで示します。[検証範囲](docs/VALIDATION.md)・[署名と配布](docs/RELEASE.md)・[変更履歴](CHANGELOG.md)も参照してください。

## ビルド
Android 8.0以上（API 26）、target/compile API 36。JDK 17と同梱のGradle wrapperを使用します。
```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
```
製品版APK/AABには所有者が管理する署名鍵が必要です。デバッグAPKの名前変更を製品版署名の代わりにしません。

## 制約
通知は端末内の予約通知であり、FCMによる即時リモートプッシュではありません。バックグラウンド処理はOSの制約で遅延します。Web Push、メモの端末間同期、ヒンジ位置を使うFlexモードは未実装です。Galaxy/Fold実機での総合検証は必要です。GitHub公開だけでAndroidのインストール警告がなくなるわけではありません。
