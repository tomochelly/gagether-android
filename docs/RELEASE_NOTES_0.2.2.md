# GAGETHER 0.2.2-beta

Android 8 이상에서 사용할 수 있는 테스트 버전입니다.

- 명일방주·소녀전선2 중국 서버 일정 때문에 앱의 전체 일정 동기화가 실패하던 문제를 수정했습니다.
- 해당 두 게임의 중국 서버 선택을 알림과 위젯에도 반영했습니다.
- 기존 0.2.1-beta와 같은 앱 ID·서명, 더 높은 versionCode로 빌드했습니다.

`GAGETHER-0.2.2-beta.apk`가 설치 파일입니다. `Source code (zip/tar.gz)`는 개발용 소스이며 설치 파일이 아닙니다.

이 파일은 디버그 서명의 테스트 APK입니다. GitHub에서 받더라도 Galaxy의 외부 앱 설치 경고가 나타날 수 있습니다. 일반 이용자용 스토어 출시는 아직 완료되지 않았습니다.

Debug와 Release 단위 테스트 각 12개 및 APK 빌드를 확인했습니다. Galaxy/Fold 실기기 설치, 알림 수신과 위젯 표시 검수는 별도로 필요합니다.
