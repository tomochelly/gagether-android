# GAGETHER 1.0.6

- Show official date-only schedules in home screen widgets, including previously missing Korean Trickcal, Honkai Impact 3rd and Reverse: 1999 periods. Dates display without an invented clock or countdown.
- Preserve existing exact-time schedule reminders. Date-only widget records do not create notification alarms.
- Keep followed-game selections, regional choices and existing notification settings. Limbus Company, Duet Night Abyss and hololive Dreams remain supported.
- The website calendar now remembers selected games, multiple schedule types and the last viewed schedule tab on the device. Calendar selections are independent of dashboard filters and followed games.

Install over the existing official app. No uninstall or data clearing is needed. The signing certificate remains the same. Push settings and account data are unchanged.

Validation: 49 Android unit tests, release APK build, and Android API30/API36 runtime checks before publication. A physical home-screen-widget test is separate; no physical-device result is claimed.
