# GAGETHER 1.0.5

- Add an independent, optional switch for game announcements. It is off by default, including for existing installations.
- Subscribe only to actual My games and the current app language. Changing games, language, account or consent updates subscriptions. Schedule reminder selections remain independent.
- Check notification permission, quiet hours, expiry and duplicate message IDs before showing an announcement. Tapping opens the matching game.
- Keep local schedule reminders, widgets, saved choices and the existing release signing identity.

The announcement server is being verified separately. Installing this update does not turn on announcement consent. Enable Game announcements in app settings only if you want to receive them. Delivery depends on Android, network and battery policies.
