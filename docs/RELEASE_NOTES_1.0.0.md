# GAGETHER 1.0.0

## 한국어

0.2.4를 기반으로 정리한 첫 1.0.0 소스 릴리스입니다. 관심 게임 연동, 크기 조절 위젯, 세부 기기 예약 알림, 선택형 심플 화면과 개인 달력 기록을 포함합니다. 영어·일본어 프로젝트 소개를 추가했습니다. versionCode는 7입니다.

서명된 설치 파일과 실기기 검증은 별도입니다. 기존 beta APK를 이름만 바꿔 정식 APK로 배포하지 않습니다. 이 문서를 추가한 것만으로 GitHub Release나 스토어 출시가 완료되지 않습니다.

## English

The first 1.0.0 source milestone, based on 0.2.4: followed games, resizable widgets, configurable local reminders, optional compact mobile UI and personal calendar records. English and Japanese project documentation is included. Android versionCode: 7.

Signed binaries and device validation are separate release requirements. This source milestone does not claim store approval, FCM push or completed device QA. Do not relabel an existing beta APK as a production build.

## 日本語

0.2.4を基にした初の1.0.0ソースリリースです。お気に入り連携、可変サイズのウィジェット、細かな端末内通知設定、シンプル表示、個人カレンダー記録を収録します。英語・日本語の紹介文を追加しました。versionCodeは7です。

署名済みバイナリと実機検証は別途必要です。ストア承認、FCMプッシュ、実機検証の完了を示すものではありません。既存のベータAPKを製品版として改名しません。
