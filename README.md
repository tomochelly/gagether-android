# GAGETHER Android

한국어 · [English](README.en.md) · [日本語](README.ja.md)

> 여러 게임의 픽업과 이벤트, 놓치기 쉬운 마감까지. 내 게임의 일정을 한곳에 모으는 Android 캘린더입니다.

**GAGETHER(가게더)**는 ‘가챠 게임 캘린더’를 줄인 이름입니다. 게임마다 흩어진 공지를 찾아다니는 시간을 줄이고, 관심 게임의 다음 일정을 모바일 화면·홈 화면 위젯·기기 알림으로 확인할 수 있도록 만들었습니다.

[웹에서 사용하기](https://gagether.wiki) · [릴리스 / 다운로드](https://github.com/tomochelly/gagether-android/releases) · [변경 이력](CHANGELOG.md)

## 한눈에 보기

| 기능 | 할 수 있는 일 |
| --- | --- |
| 내 게임 | 관심 게임과 실제 서비스 지역을 선택해 일정 모아보기 |
| 홈 화면 위젯 | 다음 일정, 스크롤 일정 목록, 게임별 일정을 크기에 맞춰 표시 |
| 맞춤 알림 | 콘텐츠별 시작·종료와 여러 사전 알림 시점 설정 |
| 모바일 심플 화면 | 일러스트를 필요할 때 펼쳐 보고 스크롤 줄이기 |
| 개인 캘린더 | 메모, 뽑기 기록, 개인 일정을 현재 기기에 저장 |
| 웹·앱 연동 | 웹 정보와 화면 변경을 APK 재설치 없이 반영 |

**시작하기:** 웹에서 로그인 없이 둘러볼 수 있습니다. Android 설치 파일과 소스 압축은 구분해서 제공하며, 현재 배포 상태는 아래 안내와 Releases에서 확인할 수 있습니다. 알림은 기기 예약 방식입니다.

## 포트폴리오 소개

게임과 서비스별로 흩어진 공지·일정을 한곳에서 확인하려는 문제에서 시작한 개인 기획 프로젝트입니다. 기획자가 정보 우선순위와 이용자 피드백에 따른 개선 방향을 정하고, AI 도구를 활용해 구현·조사·테스트를 진행했습니다. 기획·구현·검증의 범위는 문서로 구분하고, 실기기 검증이나 성능 측정이 남은 부분도 함께 기록합니다.

이 저장소는 Android Java 기반 WebView, 네이티브 예약 알림, RemoteViews 위젯과 데이터 검증을 다룹니다. 웹 서비스는 별도의 React/TypeScript 코드이며 운영 DB·서명 키·게임 이미지 원본은 여기에 포함하지 않습니다. 핵심 설계는 웹과 앱의 역할 분리, 실제 서버와 표시 언어의 분리, 불확실한 일정의 알림 제외, 사용자 데이터 보존입니다. 구현 범위와 미검증 항목을 아래 문서에서 구분합니다.

가게더 가챠 게임 캘린더의 Android 앱입니다. [gagether.wiki](https://gagether.wiki)의 모바일 화면에 기기 알림과 홈 화면 위젯을 결합합니다. Android 8.0(API 26) 이상을 지원하며 Android 16(API 36)을 대상으로 빌드합니다. 현재 제공 APK는 테스트용 debug 서명이며 Play Store/Galaxy Store에 배포한 정식 버전이 아닙니다.

소스 코드와 빌드 문서는 이 저장소에, 설치 파일은 GitHub Releases에 둡니다. GitHub의 `Source code (zip/tar.gz)`는 소스 압축이며 설치 파일이 아닙니다. [배포·서명 안내](docs/RELEASE.md) · [변경 이력](CHANGELOG.md)

## 설치 및 설정

1. 테스트에 참여한다면 제공된 `GAGETHER-0.2.4-beta.apk`를 사용합니다. 일반 이용자용 스토어 출시는 준비 중입니다. 스토어 밖 APK에는 Galaxy의 설치 출처 경고가 표시될 수 있습니다.
2. 앱을 열면 로그인 없이 일정 화면이 표시됩니다. 기존 베타를 설치했다면 같은 서명과 앱 ID를 사용하는 업데이트로 설치합니다.
3. 대시보드에서 **내 게임**을 등록한 뒤 하단 **앱 설정 → 내 게임과 연동**을 켭니다. 별도 게임 선택도 가능합니다.
4. **일정 알림**을 켜고 알림 권한을 허용합니다. 픽업·무기·이벤트·패키지별 시작/종료 알림을 켜고, 3일·2일·1일·1시간 전·정시 또는 직접 입력(0~7일)을 각각 선택합니다. 야간 시간의 알림은 생략합니다.
5. **테스트 알림**으로 권한을 확인하고 **홈 화면 위젯 추가**를 누릅니다. 위젯 크기를 늘리면 스크롤 가능한 일정이 표시됩니다.

알림을 끈 상태에서도 선택한 게임의 위젯을 사용할 수 있습니다. 일정이 없거나 연결이 끊긴 상태는 위젯에 따로 표시됩니다. 위젯과 알림을 누르면 해당 일정 상세 화면이 열립니다.

## 웹과 앱의 연결

- 앱 본문: `https://gagether.wiki/mobile`
- 공통 데이터: 기존 `/api/data`의 사용자 편집이 적용된 결과.
- 네이티브 일정: `/api/mobile/data?locale=ko`의 읽기 전용 요약. 실제 서버별 canonicalRegion을 따르며 중국 서버는 명일방주·소녀전선2만 독립적으로 지원합니다.
- 열린 앱은 20초마다 변경 여부를 확인합니다. 화면 소스 배포도 버전 변경을 감지하여 다시 읽습니다. 앱 복귀 시에도 동기화합니다.
- 백그라운드는 Android JobScheduler로 15분 주기의 동기화를 요청합니다. 실행 시각은 OS와 절전 상태가 결정하며 정확한 15분 간격을 보장하지 않습니다.
- 알림은 기기 예약 알림입니다. 네트워크 연결 여부와 별개로 저장된 일정을 사용하지만 24시간 이상 동기화되지 않은 데이터의 알림은 억제합니다. 데이터에서 삭제·변경된 일정은 다음 동기화에서 취소·재예약합니다.
- Firebase/FCM 프로젝트 및 전송 서버는 연결하지 않았습니다. 새 공지의 즉시 서버 푸시와 기기 예약 알림은 별개입니다.
- 웹 UI와 정보 수정에는 APK 재설치가 필요 없습니다. 네이티브 위젯·권한·알림 처리 코드 변경에는 새 APK가 필요합니다.

## Galaxy / Fold 대응

- 고정 방향이나 화면 비율 없이 화면 폭으로 배치합니다.
- 좁은 커버 화면·휴대폰·분할 화면: 한 열, 달력 아래 일정 목록.
- 넓은 내부 화면·태블릿: 달력과 일정 목록을 나란히, 픽업 카드 두 열.
- 접힘/펼침·회전·창 크기 변경에서 WebView를 유지하고 선택한 게임·상세·달력 날짜를 보존합니다.
- 시스템 글자 크기, 상태 표시줄, 내비게이션 바, 화면 잘림 영역, 키보드 영역을 반영합니다.
- Android 13 이상은 현재 뒤로가기 콜백을 사용하고, 이전 버전은 기존 콜백으로 상세 화면과 앱 설정을 닫습니다. Android 16의 뒤로가기 동작 변경에 대응합니다.
- 위젯은 가로·세로 크기 조절과 네이티브 남은 시간 표시를 지원합니다.
- 현재는 사용 가능한 화면 폭을 기준으로 동작합니다. 반쯤 접힌 상태의 힌지 위치를 읽어 상·하단을 별도로 배치하는 Flex 모드는 구현하지 않았습니다.

## 보안 및 데이터

일정과 위젯은 공개 읽기 API를 사용합니다. 로그인 쿠키나 서비스 비밀 키를 사용하지 않습니다. 관리자 편집은 별도의 소유자 로그인을 통해 보호합니다. 네이티브 메시지는 지정된 HTTPS Site의 최상위 문서에서만 받습니다. 인증서 오류를 무시하지 않으며 다른 사이트 링크는 외부 브라우저로 엽니다. 편집 API·자동 갱신 데이터·업로드 원본은 앱 구현에서 변경하지 않습니다.

## 빌드

JDK 17, Android SDK Platform 36, Build Tools 35.0.0이 필요합니다.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

출력: `app/build/outputs/apk/debug/app-debug.apk`. Gradle 8.13 및 배포 파일 SHA-256이 wrapper에 고정되어 있습니다. 정식 배포 시 소유자가 관리하는 릴리스 서명 키를 별도로 구성합니다. [출시용 APK/AAB 설정](docs/RELEASE.md#출시용-빌드)을 참고하세요. 키·SDK 경로·빌드 결과는 소스 저장소에 포함하지 않습니다.

## 검증 범위

기존 알림 규칙 테스트에 혼합 서버 피드 수신, 중국 서버 허용 범위, 게임별 서버 선택, 잘못된 데이터 거부 검사를 추가했습니다. 로컬 검증의 정확한 결과는 `docs/VALIDATION.md`에 기록합니다. GitHub Actions의 결과는 저장소 업로드 후 별도로 확인해야 합니다.

실제 Galaxy/에뮬레이터와 브라우저 화면 검수는 이 환경에서 수행하지 못했습니다. 설치 후 다음 항목을 확인해야 합니다.

| 확인 환경 | 확인 항목 |
| --- | --- |
| Galaxy 일반 화면 / Fold 커버 | 좁은 폭, 긴 한국어·일본어 이름, 글자 크기 확대 |
| Fold 펼침 / 가로 / 분할 화면 | 선택 게임·날짜 유지, 카드 및 달력 재배치 |
| 공개 접속 | 로그인 없이 화면 로드, 기기 재시작 후 데이터 재조회 |
| 알림 허용 / 거절 / 절전 | 테스트 알림, 예약 알림, 중복 방지, 지연 표시 |
| One UI 홈 위젯 크기 조절 | 1–3개 일정, 카운트다운, 상세 이동, 새로고침 |
| 오프라인 | 재시도 화면, 동기화 상태, 오래된 일정 알림 억제 |

실기기에서 확인하지 않은 공개 접속·알림 수신·위젯 렌더링은 검수 완료로 간주하지 않습니다.

## 0.2.3 위젯

- 다음 일정(기본 4×2), 일정 목록(4×4), 게임별 일정(4×4)을 선택합니다. 실제 셀 크기는 런처 설정에 따라 다릅니다.
- Android 12 이상은 폭·높이에 맞는 반응형 RemoteViews를 사용하며, Android 8–11은 크기 변경과 세로·가로 레이아웃으로 대응합니다.
- 큰 위젯은 모든 선택 게임의 검증된 시각을 가진 현재·향후 90일 일정을 스크롤합니다. 알림 권한을 꺼도 위젯은 사용할 수 있습니다.
- 예정 시작과 진행 중 종료를 구분하며, 3일 이내 종료는 강조합니다. 게임별 위젯은 가까운 일정이 있는 게임부터 묶습니다.
- 홈 화면 위젯 크기 자체를 앱이 임의로 늘리지는 않습니다. 사용자가 크기를 늘리면 보이는 행 수가 증가합니다.
- 실기기 Galaxy/Fold 및 홈 런처 표시 검수는 수행하지 못했습니다.

## 0.2.4 개인화

- 모바일 상단의 **기본 / 심플**에서 보기를 선택합니다. 심플은 주간 달력, 작은 일정 행, 펼칠 때만 로드하는 일러스트로 구성됩니다. 기본 보기는 유지합니다.
- 대시보드와 게임 달력에서 날짜를 고르고 **기록 추가**로 메모·뽑기 기록·개인 일정을 저장합니다. 기록은 해당 앱/브라우저의 로컬 저장소에 남습니다. 기기 간 동기화나 개인 기록의 알림은 제공하지 않습니다. 앱 데이터 삭제·제거 시 사라질 수 있습니다.
- **캐릭터 말투**는 선택 사항입니다. 동일 회차와 시각의 캐릭터 픽업을 하나의 알림으로 묶고 설정된 시간 순서에 따라 캐릭터를 순환합니다. 현재 한국어 치사·유노 문구만 검수했고, 다른 캐릭터·언어에는 일반 알림을 사용합니다. 문구 근거와 창작 표시는 앱 설정에서 확인합니다. 다른 의상·후보·하위 등급·서포트 카드를 대신 화자로 쓰지 않습니다.
- 기기 예약 알림은 인터넷 없이도 예약된 시각에 실행할 수 있지만 24시간 이상 오래된 자료는 억제합니다. OS 절전·권한·강제 종료에 따라 지연되거나 생략될 수 있습니다. 서버 원격 푸시와 모바일 브라우저의 Web Push는 아직 연결하지 않았습니다.
